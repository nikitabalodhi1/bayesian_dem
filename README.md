# Bayesian DEM

Bayesian Deep Learning approach for uncertainty-aware Differential Emission Measure (DEM) estimation in the solar corona from SDO/AIA observations.

This repository implements a Bayesian convolutional neural network that infers a DEM map from six-channel solar EUV images captured by the Atmospheric Imaging Assembly (AIA) instrument on NASA's Solar Dynamics Observatory (SDO). The model is designed to estimate not only the DEM but also uncertainty through Monte Carlo dropout and a learnable noise model.

## Repository contents

- `bayesian_dem_model.py` — model architecture, loss functions, scaling utilities, and Monte Carlo inference helpers
- `train_model.py` — training pipeline, dataset preparation, and optimizer setup
- `test_model.ipynb` — notebook for model testing/inference on sample data
- `test_simulated_data.ipynb` — notebook for checking results on synthetic/simulated inputs
- `k_matrix.npy` — AIA temperature-response kernel used to synthesize AIA images from DEM predictions
- `dropout_weights.h5` — pretrained model weights generated by the training script

## Model summary

The network takes a 6-channel AIA image tile as input and predicts:

- A DEM map with 18 temperature bins
- A reconstructed AIA image from the predicted DEM via the response kernel
- A spatial uncertainty map for the image reconstruction

Training uses a composite loss combining:

- DEM mean absolute error (MAE)
- Gaussian negative log-likelihood for AIA reconstruction

This provides both accurate DEM estimation and uncertainty-aware predictions.

## Data requirements

The training script expects local `.npy` data files containing paired AIA images and DEM targets. In `train_model.py`, the following files are referenced:

```python
/2010-09-17_split.npy
/2014-04-20_split.npy
/2014-05-18_split.npy
/2010-09-17_split_dem.npy
/2014-04-20_split_dem.npy
/2014-05-18_split_dem.npy
```

These paths are currently hardcoded as absolute paths. For a local workflow, place the corresponding data files in the expected locations or modify the file paths in `train_model.py` to point to your local dataset directory. The DEMs for training data are generated using the Regularised Inversion method given in [/demreg](https://github.com/ianan/demreg) by [Hannah and Kontar. 2012](https://arxiv.org/abs/1201.2642)

## Training

From the repository root, train the model with:

```bash
python train_model.py
```

The script:

1. Loads AIA image and DEM arrays
2. Scales the inputs for training stability
3. Builds the Bayesian CNN defined in `bayesian_dem_model.py`
4. Trains with early stopping and checkpointing
5. Saves the best model weights to `dropout_weights.h5`

## Inference and uncertainty estimation

The Bayesian model supports Monte Carlo dropout inference through the function `run_mc_inference()` in `bayesian_dem_model.py`.

A typical workflow is:

```python

# Load a single AIA image with shape (512, 512, 6)
image = ...

# Run stochastic forward passes
# dem_preds: list of DEM predictions across Monte Carlo samples
# img_preds: corresponding synthesized AIA predictions

```

The variance across stochastic forward passes provides an empirical estimate of epistemic uncertainty, while the learned noise model quantifies aleatoric uncertainty.

## Example notebooks

The notebooks in this repository provide a practical way to inspect model behavior:

- `test_model.ipynb` — run the trained model on a test image and inspect outputs
- `test_simulated_data.ipynb` — evaluate the model on simulated examples to understand reconstruction behavior

## Notes

- The model processes image tiles of size `(512, 512, 6)`.
- DEM outputs are defined on a logarithmic temperature grid spanning approximately `log10(T/K) = 5.5` to `7.2`.
- `k_matrix.npy` encodes the AIA temperature response function used to convert DEM into synthetic intensities.
